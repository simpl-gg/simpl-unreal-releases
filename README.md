# Simpl plugin for Unreal Engine

A plugin for Unreal Engine that connects a game to Simpl lobbies, queues and servers.

## Engine versions

- Used in live play on Unreal 4.27.2.
- Builds clean on an Unreal 5.7.4 source fork.
- Other 5.x versions are untested.

## Install

1. Download `Simpl-0.2.0.zip` from the [Releases page](https://github.com/simpl-gg/simpl-unreal-releases/releases).
2. Unpack it so the folder is `Plugins/Simpl` in a C++ project.
3. Enable the plugin: Edit > Plugins, then turn on Simpl.
4. Regenerate the project files and build.
